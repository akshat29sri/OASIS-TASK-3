# OASIS Task 3 - ATM Interface

This is a Java Swing based ATM interface project. It provides an ATM-style desktop window where the user can log in and perform basic banking operations.

## Features

- ATM login screen
- Balance display
- Transaction history
- Withdraw money
- Deposit money
- Transfer money to another user ID
- Quit option
- Five-class project structure

## Login Details

## Files

- `ATM.java` - application entry point
- `ATMInterface.java` - Swing user interface
- `BankAccount.java` - account and banking logic
- `Transaction.java` - transaction model
- `TransactionHistory.java` - transaction list and display logic

## How to Run

Open a terminal in this folder and run:

```bash
javac *.java
java ATM
```

## Requirements

- Java JDK 8 or later
- Desktop environment that supports Java Swing
